# Parking game — free downloads

Free full-game downloads for **Ultra Tedious Parking Simulator**.

- **Windows:** x86_64 portable ZIP. Extract the entire archive and open `Parking.exe`; keep `Parking.pck` beside it.
- **Mac Intel:** x86_64 app in a ZIP.
- **Mac Apple Silicon:** native arm64 app in a ZIP.

Extract the ZIP before opening the game. Mac apps can be moved to Applications.
No purchase, game account, or engine installation is required.

The main menu in the [browser game](https://parking-game.nascarjake.workers.dev/) also has **Download Full Game Free**.

Windows builds are unsigned. Mac apps are ad-hoc signed and are **not Apple-notarized**; operating-system download security prompts may appear. This release does not include a hosted matchmaking service. Native saves and browser saves are stored separately.

Credits and license notices are inside each archive. `SHA256SUMS.txt` provides checksums; `build-manifest.json` identifies architectures and exact build hashes. This release packages the current game snapshot; the public repository contains downloadable binaries and documentation only.

Get the latest files from the **[Releases page](https://github.com/nascarjake/parking-game-downloads/releases/latest)**.
